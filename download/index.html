Get MARSComm

The MARS digital message handler: encrypted formal traffic, chat and USMTF messages over HF radio modems.

Windows

MARSComm 4.0.5 and MS-DMT 3.3.2 · Windows 10 and 11

MARSComm installer MS-DMT installer

  1. Download and run the installer, accepting the default folder. If Windows shows Windows protected your PC, click More info, then Run anyway.
  2. For MARSComm, copy the address book files (*_AB.csv) you have been given into C:\MARSComm\Address Books.
  3. Start the program and open Help › User Guide, which walks you through setting it up.

After that, each program finds and installs its own updates.

Linux

MARSComm and MS-DMT · Debian 13 on a 64-bit PC

In a terminal, add the MARSComm package repository and install both programs:

sudo wget -O /usr/share/keyrings/marscomm-archive-keyring.gpg \
     https://marscomm.rgn9mars.com/apt/marscomm-archive-keyring.gpg
sudo wget -O /etc/apt/sources.list.d/marscomm.sources \
     https://marscomm.rgn9mars.com/apt/marscomm.sources
sudo apt update && sudo apt install marscomm ms-dmt
  1. Copy the address book files (*_AB.csv) you have been given into ~/.local/share/MARSComm/Address Books.
  2. Start MARSComm from the desktop menu, and follow Help › User Guide.

Updates then arrive with your system's other updates.

Address books and cipher keys are not included. The MARS address books list members' contact details, and the cipher keys are issued to members, so both come to you through MARS channels rather than from this page.

Already have MARSComm?

You don't need anything from this page. On Windows, MARSComm checks for updates once a day, or click Check for Updates on its Settings tab. Versions 3.65 and earlier cannot update themselves: install once from this page. On Linux, run sudo apt update && sudo apt upgrade.
